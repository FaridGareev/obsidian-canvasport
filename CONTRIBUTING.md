# Contributing to CanvasPort

Thanks for helping improve CanvasPort. Small, focused contributions are easiest to review and release.

## Before opening a pull request

1. Create a branch for one focused change.
2. Run `npm install` and `npm run verify`.
3. Add or update tests when changing export behavior.
4. Explain the user-visible result and any limitations in the pull request description.

## Reporting a problem

Please include the Obsidian version, operating system, a minimal Canvas example where possible, the selected export format, expected behavior, and the actual result. Remove private vault content before sharing files or screenshots.

## Style

Keep TypeScript strict, preserve the project’s tab indentation, and avoid unrelated formatting changes. Changes must remain compatible with the minimum Obsidian version declared in `manifest.json`.
