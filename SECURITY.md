# Security policy

If you discover a security issue, please do not open a public issue. Report it to [farid.gareev@my.jcu.edu.au](mailto:farid.gareev@my.jcu.edu.au) with a clear description and reproduction steps. You will receive an acknowledgement as soon as practical.
